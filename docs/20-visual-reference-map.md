# Interpretation Rule

Visual references define:
- visual design,
- layout,
- information hierarchy.

Written requirements define:
- product behavior,
- data model,
- security,
- feature scope.

If a reference includes illustrative content that is not specified by the product documents, do not silently expand scope.

Example:
The references may show `Messages` in navigation.
The MVP does not require a full messaging subsystem unless it is separately specified.

---

# Consistency Checklist

Before marking a screen visually complete compare it to the appropriate reference for:

- sidebar width
- header height
- page padding
- title scale
- button height
- card radius
- border tone
- table row density
- chip size
- icon scale
- column spacing
- shadow strength
- muted text contrast
- chart palette
